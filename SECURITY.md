# Security

RepoReel may inspect untrusted repositories. Its default workflow therefore prefers static reads and the smallest safe, non-destructive Proof Mode experiment.

Do not use RepoReel to execute suspicious code, deploy services, migrate production data, spend money, or expose credentials just to improve a Launch Score.

If you discover a vulnerability in RepoReel itself, report it privately through the repository's security-reporting channel once the GitHub repository is published. Do not include live credentials or personal data in public issues.
