Evidock is an open-source Agent Skill for one question:

Is your repository actually ready to launch?

Give it a GitHub URL or local repo. It audits the Front Door, verifies claims, runs scoped proof when safe, gives a deterministic Launch Score, fixes evidence-backed launch blockers, then generates a before/after diff and badge.

Evidence before you ship.
