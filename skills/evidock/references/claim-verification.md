# Claim Verification v0.6

Verify consequential public claims from README, landing/demo copy, docs, package metadata, screenshots, and launch material.

Procedure: extract factual claims that could affect a user's decision; ignore harmless slogans unless they imply capability; find strongest supporting and conflicting evidence; prefer runtime/test evidence for behavior when safe; classify VERIFIED / INFERRED / UNKNOWN / CONTRADICTED.

Missing evidence → UNKNOWN, not CONTRADICTED. A partial implementation contradicts a broad claim only when the advertised result cannot actually be achieved. Runtime proof applies only to the stated execution scope.
