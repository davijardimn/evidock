# Evidence Model v0.6

Claim states: VERIFIED, INFERRED, UNKNOWN, CONTRADICTED.

Evidence classes: FRONT_DOOR, STATIC, TEST, RUNTIME, GIT, USER_SUPPLIED.

Runtime evidence beats marketing claims for behavior actually exercised. Tests verify tested behavior only. Manifests verify declared dependencies, not successful installation. A documented command proves documentation exists, not that the command works. A filename alone is weak evidence. Absence in partial scope is not proof of global absence.

Every scored criterion needs one concise evidence sentence, preferably naming paths, commands, observed output, or scope.
