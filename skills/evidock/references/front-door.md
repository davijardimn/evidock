# Front Door Model v0.6

The **Front Door** is what a prospective user can understand before they execute the project or inspect implementation details.

Primary surfaces: README opening/repository landing content; repository description/topics when available; hero/demo/output embedded or obviously linked; package metadata intended for discovery; explicit docs linked from opening README.

Application templates hidden inside source are not Front Door evidence unless directly accessible via an obvious demo/site link or supplied live-project evidence.

Keep project understanding separate from Front Door clarity. Only the latter earns Discovery points.

A strong ten-second Front Door answers: what is it, who is it for, what outcome, why choose it, what does it look like/output, and what is the next step.
