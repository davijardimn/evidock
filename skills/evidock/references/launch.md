# Launch Copy v0.6

Generate launch material only from verified evidence and explicitly framed inferences.

## Channel principles

- **GitHub:** clear identity, real proof, quick start, trust.
- **Hacker News:** concrete problem, mechanism, technical honesty; avoid hype.
- **Reddit:** context + what was built + useful detail; avoid drive-by promotion.
- **X/social:** one strong outcome + visual proof + link; no fake urgency.
- **GitHub Release:** factual changes, migration/breaking notes, verification status.

Never invent usage numbers, star counts, benchmarks, testimonials, customer names, or "production-ready" claims.
